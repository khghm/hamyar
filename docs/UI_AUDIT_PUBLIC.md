## ترتیب پیشنهادی رفع (بدون اجرا)

1. حذف ارجاع‌های `image.qwenlm.ai` و جایگزینی با تصاویر محلی/باكت Storage + تصویر پیش‌فرض برند.
2. اصلاح دادهٔ تاریخ اخبار (تبدیل یک‌بارهٔ مقادیر شمسی به میلادی) و یکسان‌سازی فرمت تاریخ در CMS.
3. بازطراحی هدر (کاهش آیتم‌های اصلی + منوی «بیشتر») و هیروی خانه/صفحات داخلی.
4. کارت‌های محصول/خدمت: تصویر، مزیت کلیدی، قیمت، یک CTA واحد.
5. یکسان‌سازی کنترل‌های فیلتر و ریتم فاصله‌ها؛ افزودن اسکلتون و حالت خالی.
6. پاس نهایی دسترس‌پذیری (کنتراست، aria، فوکوس) و تایپوگرافی.
