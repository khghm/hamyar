# سیستم طراحی «کافی نت همیار»

این سند مرجع تصمیم‌های بصری است. هر تغییر ظاهری باید از توکن‌ها و کلاس‌های
`index.css` استفاده کند؛ مقادیر خام (رنگ هگز، شعاع، سایه) در کامپوننت‌ها
تکرار نمی‌شود.

## ۱) توکن‌ها (`src/index.css` → `@theme`)

| گروه | توکن‌ها |
|---|---|
| برند | `brand-50 … brand-950` (پایه: `brand-600 #2563eb`) |
| اکسنت | `accent-400/500/600` (فقط برای تأکید و بج، نه CTA اصلی) |
| معنایی | `success`, `danger`, `warning`, `info` |
| سطح | `surface`, `surface-muted`, `surface-sunken`, `border-subtle` |
| متن | `ink`, `ink-muted` |
| گردی | `radius-btn 12px`, `radius-card 16px`, `radius-panel 24px` |
| سایه | `shadow-card`, `shadow-pop`, `shadow-brand` |
| فونت | `font-sans` (Vazirmatn) |

## ۲) تایپوگرافی

- `display` (۳۲–۵۶px): فقط هیروی صفحهٔ اصلی.
- `h1` (۲۸–۴۴px) · `h2` (۲۲–۳۰px) · `h3` (۱۷–۲۰px)
- `body-text` ۱۵px / line-height ۱.۹۵
- `meta` ۱۳px / ۱.۸
- `eyebrow` ۱۲px، وزن ۷۰۰، رنگ برند (بالای تیترها)
- `measure` برای طول خط مقاله (۶۸ کاراکتر)
- اعداد: همیشه `tnum` و با `faNum`/`faPrice` از `src/utils/format.ts`.

## ۳) رنگ

- **یک** CTA اصلی در هر نما: `btn-primary`.
- لینک‌ها `brand-700`، متن اصلی `ink`، متادیتا `ink-muted`.
- گرادیان فقط در هیرو/CTA پایانی؛ بیش از دو گرادیان در یک صفحه ممنوع.
- بج‌ها فقط از `badge-brand/success/warning/danger/neutral`.
- کنتراست حداقل AA: متن ≥ ۴.۵:۱ و متادیتا ۱۳px.

## ۴) چیدمان

- `container-page`: `max-w-7xl` + پدینگ ۱۶/۲۴.
- `section`: `padding-block: clamp(2.5rem, 6vw, 5rem)`؛ `section-tight` برای بلوک‌های کم‌ارتفاع.
- برای ریتم، بخش‌ها یکی‌درمیان `section-alt` بگیرند.
- هیرو بدون ارتفاع ثابت؛ با `clamp` و حداکثر ۲ خط تیتر.
- `section-head` برای ردیف «تیتر + لینک همه».

## ۵) کامپوننت‌ها

| کلاس | کاربرد |
|---|---|
| `btn` + `btn-primary/secondary/ghost/danger` + `btn-sm/lg` | همهٔ دکمه‌ها |
| `btn-icon` | دکمهٔ فقط-آیکون (۴۰×۴۰) |
| `card` + `card-hover` | همهٔ کارت‌ها |
| `input`, `label`, `hint`, `field-error` | فرم‌ها |
| `badge-*`, `chip`, `chip-active` | وضعیت و فیلترها |
| `skeleton` | حالت لودینگ |
| `reveal` + `useReveal()` | ورود نرم بخش‌ها |
| `sticky-buy` / `StickyBuyBar` | نوار خرید موبایل |
| `skip-link` | پرش به محتوا (در PublicLayout) |

## ۶) تصویر

- نسبت ثابت: محصول و مقاله `4:3`، مدیا `2:3`، آواتار ۱:۱.
- تصویر بدون `src` یا خطادار → `BrandVisual` (گرادیان برند + آیکون موضوعی).
- عکاسی: پس‌زمینهٔ خاکستری روشن، نور یکنواخت، حداقل ۳ زاویه برای محصول.
- `loading="lazy"`، `decoding="async"`، `width/height` برای جلوگیری از CLS.
- لوگوی هدر: نسخهٔ بهینهٔ ۱۹۲px (`public/brand-logo.png`).

## ۷) حرکت

- ۱۵۰–۲۵۰ms، `ease-out`؛ هاور حداکثر ۲px جابه‌جایی.
- `prefers-reduced-motion` در CSS و `useReveal` رعایت شده است.
- یک الگوی حرکت امضادار: ظاهر شدن نرم بخش‌ها هنگام اسکرول.

## ۸) دسترس‌پذیری

- `skip-link` بالای صفحه.
- `:focus-visible` سراسری با حلقهٔ برند.
- هدف لمسی دکمه‌ها ≥ ۴۴px در موبایل.
- `aria-label` روی دکمه‌های آیکونی؛ `alt` معنادار برای تصاویر محتوایی.
- `h1` یکتا در هر صفحه (شامل صفحه‌های خالی سبد/ورود).

## ۹) لحن

- فارسی رسمیِ صمیمی، بدون اصطلاح انگلیسی اضافه.
- پیام‌های خطا: «چه شد + چه کار کند» (مثل «شماره موبایل معتبر نیست (مثال: 09121234567)»).
- اعداد و واحدها همیشه فارسی؛ شمارهٔ تلفن با `dir="ltr"`.

## ۱۰) کنترل کیفیت بصری

```bash
node scripts/visual-qa.mjs   # اسکرین‌شات ۴ بریک‌پوینت از صفحه‌های کلیدی
```

- بریک‌پوینت‌ها: ۳۶۰، ۷۶۸، ۱۰۲۴، ۱۴۴۰.
- چک‌لیست: سرریز افقی، کنتراست، فوکوس با Tab، حالت تاریک، حالت خالی، لودینگ.
- تست: `npx tsc --noEmit`، `npx vitest run`، و بازبینی اسکرین‌شات‌ها در `.screens/`.
